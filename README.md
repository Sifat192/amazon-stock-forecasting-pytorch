# Amazon Stock Forecasting with PyTorch LSTM

A time-series learning project that uses a PyTorch Long Short-Term Memory (LSTM) network to predict Amazon’s next trading-day closing price from the previous seven observed closing prices.

## Project Overview

This project covers:

- Exploring historical stock prices and trading volume.
- Preparing sliding windows for sequence modeling.
- Splitting observations chronologically into training and test sets.
- Standardizing data using training-fitted statistics.
- Building and training an LSTM regression model in PyTorch.
- Evaluating predictions against a previous-close baseline.

## Dataset

The dataset contains **6,516 observations**, covering **May 15, 1997, to April 5, 2023**.

| Column | Description |
|---|---|
| Date | Trading date |
| Open | Opening price |
| High | Highest price during the trading day |
| Low | Lowest price during the trading day |
| Close | Closing price |
| Adj Close | Adjusted closing price |
| Volume | Trading volume |

This experiment uses **Close** as its only input variable and prediction target.


The EDA notebook reads `AMZN.csv` and exports `Amazon_stock_closing_prices.csv`.

## Methodology

### 1. Exploratory Data Analysis

Inspect the dataset’s dimensions, missing values, duplicates, and date coverage. Visualize closing prices and trading volume, then export the closing-price series.

### 2. Sequence Preparation

Each input contains seven consecutive observed closing prices, ordered from oldest to newest. The target is the following trading day’s closing price.

- Input shape: `(batch_size, 7, 1)`
- Target shape: `(batch_size, 1)`
- Total prediction examples: **6,509**

The lookback refers to seven trading observations, not seven calendar days.

### 3. Chronological Splitting and Scaling

The first **95% of prediction examples** are used for training, and the remaining **5%** are used for testing:

- Training examples: **6,183**
- Test examples: **326**

The scaler is fitted on training data only and reused to transform the test data.

### 4. LSTM Model

A single LSTM layer processes each sequence. A linear layer converts the final timestep’s hidden representation into one predicted closing price.

| Setting | Value |
|---|---|
| Input features per timestep | 1 |
| Lookback | 7 trading observations |
| LSTM layers | 1 |
| Hidden units | 4 |
| Output units | 1 |
| Loss function | Mean squared error |
| Optimizer | Adam |
| Learning rate | 0.001 |
| Batch size | 32 |
| Epochs | 15 |
| Random seed | 42 |

Hidden and cell states are reset between batches.

## Evaluation

The training loop reports mean squared error on standardized prices. For interpretable evaluation, predictions are converted back to original price units and assessed using:

- **MAE:** Mean absolute prediction error.
- **RMSE:** Root mean squared prediction error.
- **Previous-close baseline:** Predicting that the next closing price equals the most recently observed closing price.

Actual-versus-predicted plots help inspect errors over time. Training-set plots show model fit; test-set plots show performance on held-out observations.

Numerical results should be taken from the corrected notebook’s saved execution outputs. Decreasing training loss alone does not demonstrate useful forecasting performance.

## Limitations

- This is an educational experiment using one stock and one historical train/test split.
- Only closing prices are used; other market variables and external information are excluded.
- Each test prediction uses the previous seven actual observations. This is rolling one-step prediction, not a forecast of the entire test period made at once.
- The current training loop monitors test loss each epoch. A separate validation period is needed before using evaluation loss to select epochs or hyperparameters.
- Fixed random seeds improve repeatability, but exact results may vary across software versions and hardware.
- This project does not evaluate a trading strategy or establish profitability.
